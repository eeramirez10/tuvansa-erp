# UI System Legacy

## Inputs
- `LegacyInput`: editable.
- `LegacyField`: solo lectura (bloqueado visualmente).

## Estilo base legado
- Tamano pequeno (alto ~18px/19px).
- Bordes grises y densidad alta.
- Tipografia compacta.
- Sin scroll en vistas principales; scroll solo en modales.

## Regla
No cambiar espaciado/tamanos globales sin comparar contra captura legacy del modulo.
